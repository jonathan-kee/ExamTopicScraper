# Question 168
Which two are true about constraints? (Choose two.)

# Answers
A column with a FOREIGN KEY constraint can never contain a NULL value. A.

A column with a UNIQUE constraint can contain a NULL value. E.

A constraint can be disabled even if the constrained column contains data. B.

All constraints can be defined at the table or column level. D.

C. Constraints are enforced only during INSERT operations.
