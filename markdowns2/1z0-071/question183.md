# Question 183
Which two statements are true about substitution variables?

# Answers
A substation variable prefixed with && prompts only once for a value in a session unless it is set to undefined in the session. D.

A substitution variable can be used only in a SELECT statement. A.

A substitution variable can be used with any clause in a SELECT statement. C.

A substitution variable prefixed with & always prompts only once for a value in a session. E.

A substitution variable used to prompt for a column name must be enclosed in double quotation marks. B.

A substitution variable used to prompt for a column name must be enclosed in single quotation marks. F.
